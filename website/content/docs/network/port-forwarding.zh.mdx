## 规则

本地、远程、SOCKS5 和 HTTP CONNECT 规则：

- **仅回环**：只监听回环接口，
- **持久化**：随主机保存，
- **显式启动**：不会自动开始。

隧道会随拥有它的 SSH 标签页一起停止。

## 跳板路由

跳板路由会独立校验并认证每一跳，每一跳使用各自的主机密钥和凭据。

## 出站代理

出站 SOCKS5 或 HTTP 代理用来承载最初的连接。

## X11 转发

X11 转发会先校验远端客户端使用的每会话伪造 cookie，再把它替换成本地的 Xauthority
cookie，因此真正的 cookie 不会交给远端。
