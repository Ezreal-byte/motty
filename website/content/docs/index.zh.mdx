title: Motty
description: SSH、SFTP、端口转发、VNC/RDP 和 AI 助手，都在一个原生窗口里。
---

Motty 是一个原生桌面 SSH 工作区。它用 Go 编写，构建在
[Viva](https://github.com/vivaui/viva) 上：应用里没有 Electron、没有内嵌浏览器，
也没有 JavaScript 层。
