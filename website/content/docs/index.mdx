---
title: Motty
description: SSH, SFTP, port forwarding, VNC/RDP and an AI assistant in one native window.
---

Motty is a native desktop SSH workspace. It is written in Go on
[Viva](https://github.com/vivaui/viva), so there is no Electron runtime, no embedded
browser and no JavaScript layer in the application.
