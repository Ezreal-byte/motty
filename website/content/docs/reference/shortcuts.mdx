title: Keyboard shortcuts
description: Default shortcuts. All of them are configurable.
---
The defaults use Command on macOS and Control on Windows and Linux. Every shortcut
can be changed in settings.

Inside a remote-desktop tab Motty's shortcuts are suspended and keys go to the
remote. **Ctrl+Alt+G** releases the keyboard.
