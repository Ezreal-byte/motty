# End to end: a VNC host reached through SSH, against the loopback SSH fixture
# (port 2222, allowed to reach 127.0.0.1:5901) and a real VNC server there (see
# tools/live/vnc_live.sh docker). The password of the fixture is "secret", the VNC
# server's "motty-pw". The UI language of the machine decides the labels below;
# these are the Chinese ones.
#
#   go build -tags vivahead -o /tmp/motty-head ./cmd/motty
#   python3 tools/headless_drive.py "$(mktemp -d)" tools/e2e/vnc_e2e.txt
#
# The SSH host is saved first: the VNC host goes through the saved SSH host with
# the same address and account, so its port 2222 applies (and its jump route and
# algorithms would).
