# 多主机监控面板

左侧「监控」提供独立于终端的多主机面板。创建和切换面板不会连接主机，必须点击「开始监控」。SSH 配置、跳板、代理、密码库及认证弹窗沿用现有连接流程，不会创建隐藏终端。

## 使用方式

- 新建面板：名称必填，备注可选，搜索名称、地址、分组或标签后跨组选择 SSH 主机。面板使用 Viva Select 切换，右侧提供编辑、主机排序和删除入口；备注仅在编辑弹窗中显示。新建和编辑共用顶部「选择主机 / 排列顺序」两个 Viva Tab。排序页隐藏名称、备注表单，将空间交给滚动列表；拖拽行四周留出空间以保留完整边框。选择页使用最多三列、单行图标与名称的紧凑主机小卡，按分组展示；关键字、分组下拉框与「仅已选」可组合筛选，保留过滤范围以外的选择及其顺序，并显示结果数量。卡片仅绘制可见区域；顺序页使用 Viva ReorderList 拖动已选主机，也支持键盘上下 / Home / End 调整。保存后简洁、详细模式一起采用新顺序，取消不提交草稿。
- 主机页多选后，点击「添加到监控面板」可添加到已有面板（主机自动去重），或带着已选 SSH 主机快捷创建；完成后跳转到对应监控面板。停止的面板不会因此启动采集。
- 简洁 / 详细切换与弹窗使用相同的 Viva Tabs，支持键盘移动焦点和激活。
- 简洁模式：每台主机一行，不显示常驻的「监控中」列。每台服务器的第二列提供半透明的竖向图标 Tab（概览 / 磁盘 / 网络，悬停显示名称），独立切换为该主机各分区和网卡的列表，允许同一面板混合不同主机视图；异常和连接进度仍会显示。
- 详细模式：图标、名称、IP:端口位于同一行，随后提供每台主机独立的带图标「概览 / 磁盘 / 网络」标签，各指标标题同步使用对应图标。概览展示 CPU、内存、网络曲线及磁盘容量；磁盘页展示主磁盘趋势和全部挂载分区；网络页展示主网卡趋势和各接口当前速率、累计流量。
- 采集间隔为 2、5、10、30、60 秒，默认 5 秒；保留时长为 15 分钟、1、6、24 小时，默认 1 小时。两个选项独立生效。频率旁复用单连接监控的 SVG 倒计时；停止、失败和减少动态效果时不继续播放动画。
- 已启动面板在切换页面和最小化时持续采集。同一窗口的多个面板共享主机采集源，各面板按自己的频率保存真实样本。简洁、详细及设备视角之间切换不会重新连接。
- 停止后保留并冻结曲线和真实时间轴，图表内不显示「已停止」；宽窗口仅在右上角标识停止，窄窗口保留页脚状态。重新开始追加新样本，并对暂停时段保留断点。历史仅存本次运行内存，退出清空；扩大保留时长不会补造过去数据。断连沿用已有自动重连设置，命令失败或不支持的系统等待手动处理。

## 实现边界

`internal/monitoring` 管理线程安全的面板历史、订阅和采样窗口。后台采集直接写入历史，不依赖原生窗口绘制。历史以真实时间戳记录，缺失指标保留 NaN；长窗口按时间桶保留各序列极值与缺失边界。界面按版本缓存绘制数据，不逐帧复制全部历史。开始时按已采集时段显示趋势（至少一分钟的真实时间轴），随后随数据增长到所选保留窗口，不填充虚构历史。CPU、内存及主磁盘使用固定百分比轴，网络按可见流量缩放。

`internal/workbench/monitor_dashboard*` 负责原生页面、表单、身份验证、连接生命周期和采集器适配。停止最后一个订阅会关闭该主机的采集与连接引用，不影响已有终端。取消后的旧采集结果通过代次校验丢弃。

面板引用稳定 Catalog ID，定义和选中面板设备本地保存，配置格式为 9。凭据、运行标志和历史不写入面板配置，不参与跨设备同步。已删除主机保留失效提示，可在编辑弹窗取消选择。应用重启不自动恢复监控采集。

## 验证

自动化覆盖创建校验、配置恢复不连接、真实采集结果接入、共享与停止隔离、认证、重连策略、拒绝命令、停止历史、窗口裁剪、极值与断点、取消结果隔离及并发读写。原生 headless 覆盖两种模式、每主机的详细横向标签、简洁模式第二列竖向标签及混合设备视图、创建弹窗、深浅色、中英文、窄窗口及 100%/150%/200% 缩放。截图只使用测试夹具数据，客户端本身不注入演示主机。

本机验证日志和截图输出到忽略目录 `tmp/monitor-dashboard/`。完整回归中的 Windows 环境/基线失败单独记录在该目录的验证结果中；不能将完整回归报告为全绿。测试和构建命令沿用仓库 Go 工具链和兄弟目录 Viva 替换配置。
