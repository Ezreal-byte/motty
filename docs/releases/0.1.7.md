Motty 0.1.7：快捷命令有了独立页面，每条命令都能绑定快捷键；SSH 连接可以选择 ssh-agent（支持 1Password、Bitwarden 和 Windows 命名管道）；加密私钥的口令可以存进密钥链；SSH 终端里粘贴剪贴板图片会上传到服务器并输入路径；终端配色会随浅色 / 深色外观分别记忆。

## 新功能

- **快捷命令页面和快捷键。** 侧边栏「已知主机」下面新增「快捷命令」页面，用表格管理每条命令的名称、快捷键和内容，可添加、编辑、删除；原来藏在设置里的入口移到了这里。每条命令都能绑定自己的快捷键：在编辑对话框里点「设置快捷键」再按下按键即可。快捷键不会和内置快捷键或其他快捷命令重复；只用 Control 时需要再加 Shift 或 Alt，免得占用 Ctrl+R 这类终端自带按键。它只在终端页显示时发送，不会把命令发进看不见的终端。快捷键只保存在本机，不随云同步。
- **选择 ssh-agent。** 连接设置里可以选系统 agent、1Password、Bitwarden，或自定义 socket / 命名管道，按设备保存。从 Dock 启动的应用拿不到终端里的 `SSH_AUTH_SOCK`，现在不用再靠它；Windows 默认连接 OpenSSH 命名管道，也能用 1Password 的管道。所选 agent 连不上时，会在跳过列表里写明地址。
- **保存密钥口令。** 密钥链页里加密私钥新增「保存口令」：先用口令校验密钥，再存入保险库，连接时自动取用；保存为空即清除。主机表单也会说明加密密钥会在连接时询问。
- **粘贴剪贴板图片。** 在 SSH 终端里粘贴时，如果剪贴板里是图片而没有文本，会通过 SFTP（没有 SFTP 时用 SCP）把图片传到服务器的 `~/.cache/motty/paste`，并输入它的路径，方便 Claude Code 之类的程序读取。文件和新建目录只有当前账号可读写，超过一周的上传会被清理，设置里可以关闭；本地终端和容器会话不受影响。
- **配色随外观记忆。** 终端会跟随窗口在浅色和深色之间切换，两种外观各记住自己的配色；设置里改的是当前正在显示的那一种，旧版本保存的配色会归到背景相配的外观。
- **RDP 控制台会话。** 远程桌面主机表单新增「连接到控制台（管理）会话」开关。

## 改进

- 以 `ENCRYPTED PRIVATE KEY` 开头的私钥（OpenSSL 3 和 `ssh-keygen -m PKCS8` 的默认格式）现在可以打开，并像其他加密密钥一样询问口令；存在但无法使用的密钥文件会连同原因出现在跳过列表里，不再悄悄消失。
- 本地终端的文件面板会打开并跟随 shell 所在的目录（本地 Bash / Zsh；Windows shell 暂不支持）。
- OSC 52 写剪贴板不再弹窗询问：Claude Code 的选中即复制、tmux 的 `set-clipboard` 每选一次就写一次，原来每次拖选都会弹出对话框。读剪贴板仍然拒绝；询问对话框里新增「始终允许」。
- 主机表单里私钥口令的说明改为标签旁的帮助图标，不再挤住下面一行。

## 修复

- 终端旁边打开文件面板时，终端里离左边缘与面板同宽的那一段不再吞掉滚轮。
- 远程工具窗口重新打开或恢复时会重新读取当前标签，之后新建的容器不再显示成已删除。
- 选中的终端配色现在有对勾标记；深色配色在浅色窗口里原先因为边框颜色相同而看不出选中。
- 连接时弹出的口令提示框，点在框外不再误把这把密钥跳过；未解锁前指纹未知的密钥不能再固定到某台主机，也不再阻止删除该密钥。

## 安装

| 平台 | 包 |
| --- | --- |
| macOS（arm64、amd64） | `.dmg`、`.zip` |
| Windows（amd64、arm64） | `.exe` 安装程序 |
| Linux（amd64、arm64） | `.deb`、`.tar.gz` |

`SHA256SUMS` 覆盖所有文件，`SIGNATURES` 是每个包的更新签名；安装要求见 [README](https://github.com/t8y2/motty#-install)。

macOS 包用 Developer ID 证书签名、通过 Apple 公证并 staple，可以直接打开，也能自己更新。Windows 包仍未做代码签名（还没配置证书），SmartScreen 会提示；装上这一版之后，后续更新靠更新签名校验，可以原地完成。Linux 包不做代码签名；用 `install.sh` 装到前缀的版本能自己更新，`.deb` 由包管理器升级。
