# Motty 升级验收 A — 0.1.901

这是手动安装的低版本，用于在 Windows 自定义目录中验收完整升级流程。

1. 下载安装程序，将目录选为 `D:\Program Files\motty-update-test`。
2. 启动后确认“设置 → 关于”版本为 0.1.901，可新增一个便于识别的测试连接。
3. 在“设置 → 通用”点击检查更新，应提示 0.1.902。
4. 点击“安装并重启”，确认应用内下载、校验、退出、安装并自动重启。
5. 重启后确认版本为 0.1.902、测试连接仍在、程序仍位于原安装目录。

测试应用显示为 **Motty Upgrade Test**，窗口标题为“Motty 升级验收”。
安装记录为 `dev.motty.upgrade-test`，配置位于 `%APPDATA%\motty-upgrade-test`。
两个版本都包含自定义安装目录修复，使用同一套独立测试公钥验证安装包签名。

仅 Windows amd64 验收包，适用于 Windows 10/11；此版本不发布到正式更新源。
