Motty 0.1.6：文件面板默认跟随终端所在目录，也能让终端跟着文件栏走；Windows 本地终端可以选择已安装的 Shell；新建主机时能直接选择或创建分组；WebDAV / S3 备份在明确同意后可以用远程 HTTP；窗口有了可用的最小尺寸，宽屏下 AI 面板能拉得更宽，窄窗口里工具栏不再挤坏。

## 新功能

- **文件面板跟随终端目录。** 文件面板默认跟随 SSH 终端当前目录；新连接的 Bash / Zsh 会安装仅本次会话生效的目录上报，不改动服务器上的启动文件。设置 > 文件里还有默认关闭的「终端跟随文件栏目录」：开启后进入远程文件夹也会切换同一个终端的目录，只在验证过的空提示符下同步，其余情况给出提示而不是补发命令。Bash 4.4 以下只支持跟随，反向同步保持关闭。
- **选择或创建连接分组。** 编辑主机时，分组一栏可以直接选已有分组，也能输入新名称创建，和标签的用法一致。
- **Windows 本地 Shell 可选。** 设置 > 终端新增「本地 Shell」，列出从 PATH 和常见安装目录检测到的 PowerShell、CMD、Git Bash 等；选择只保存在本机，对新建或重连的本地终端生效。
- **远程 HTTP 备份。** WebDAV 和 S3 仍默认要求 HTTPS。局域网里的 HTTP 服务可以在表单底部勾选「允许不安全的远程 HTTP」，确认后才保存，并一直显示不加密的风险；备份文件仍然在本机加密后上传。

## 改进

- 窗口、独立文件窗口和远程工具窗口都有可用的最小尺寸，缩到极限时控件不再被裁掉。
- 停靠的 AI 面板可以拉得更宽：宽度只受旁边内容保留的空间限制，状态栏导航也算作保留空间，宽屏下不再停在 760px。
- 窄窗口里，主机、密钥、代理、端口转发和已知主机页的工具栏按钮在放不下时变成带提示的图标；主机行让出状态文字、保留指示灯；标题和空状态说明会换行或省略，不再压到按钮下面。
- AI CLI 设置改为实际探测能力，不再按版本号判断：会显示自动找到的可执行文件路径或提示未找到，并分别说明缺少哪项能力、检查命令失败还是隔离设置没生效；版本未知不再算错误。
- 发布构建会先读取每个可执行文件的构建信息，确认提交、提交时间、干净状态和目标平台，再把它打进安装包；配置了 Windows 证书时，安装包里的程序也会在打包前完成签名。

## 修复

- 只允许 SFTP 的服务器不再因为 shell 被拒绝而断开整个连接，文件面板也不会再显示「SFTP worker 不可用」。用户结束 shell 时，只要文件面板或独立文件窗口仍在使用该连接，连接就留到最后一个窗口关闭。
- 文件面板的路径输入框失去焦点后，面包屑会恢复显示。
- 服务器上的 procps 较旧、进程字段不同时，远程进程列表不再解析失败。
- 文件面板正在打开、忙碌或正在编辑路径时，迟到的目录上报不会让列表跳走，只会应用最新的那一次。

## 安装

| 平台 | 包 |
| --- | --- |
| macOS（arm64、amd64） | `.dmg`、`.zip` |
| Windows（amd64、arm64） | `.exe` 安装程序 |
| Linux（amd64、arm64） | `.deb`、`.tar.gz` |

`SHA256SUMS` 覆盖所有文件，`SIGNATURES` 是每个包的更新签名；安装要求见 [README](https://github.com/t8y2/motty#-install)。

macOS 包用 Developer ID 证书签名、通过 Apple 公证并 staple，可以直接打开，也能自己更新。Windows 包仍未做代码签名（还没配置证书），SmartScreen 会提示；装上这一版之后，后续更新靠更新签名校验，可以原地完成。Linux 包不做代码签名；用 `install.sh` 装到前缀的版本能自己更新，`.deb` 由包管理器升级。
