Motty 0.1.3：文件面板改成独立双栏窗口、新增全局传输中心和可停靠的传输面板，远程工具可以开在自己的窗口里；主机新增每主机认证方式、SOCKS5/HTTP CONNECT 代理和三处配色；AI 助手能导入 magpie 与 cc-switch 的模型供应商。

## 新功能

- **独立双栏文件窗口。** SFTP 可以在自己的窗口里并排打开本地和远程两栏，支持排序、拖放，并能从主机直连；本地菜单里多余的滚动条也去掉了。
- **传输中心。** 上传下载汇总到一个全局面板，能看到进度、失败原因和任务的生命周期；关掉发起它的窗口，任务照常走完。
- **传输面板与路径栏。** 文件面板默认显示传输面板，可停靠在左侧或右侧；路径栏可以编辑并切换样式，导航失败时有全局提示，上传时会显示目标目录。
- **服务器端压缩与解压。** 远程文件夹可以直接在服务器上打包成 zip，不必先下载；解压支持更多归档格式，结果有全局提示。
- **在独立窗口里打开文件。** 图片直接预览，文本按识别出的编码打开编辑，不再占用主窗口。
- **远程工具开在独立窗口。** 远程工具从主窗口里搬进原生独立窗口，可以和主窗口并行操作；兼容旧版 Docker 和 `ps`，进入容器时用它自己的终端。
- **每个主机一套登录方式和代理。** 主机可以分别设置密码、密钥、Agent 等认证方式；也可以单独给一个主机配 SOCKS5 或 HTTP CONNECT 代理（支持用户名密码）。
- **连接配色。** 每个连接可以选一种颜色，终端顶栏和工具按钮跟着变色；表单里的颜色用圆形吸管选，主机表单的行距也重新调过。
- **主机标签多选。** 标签改成可搜索、可现场新建条目的多选框。
- **导入 magpie 与 cc-switch 的供应商。** AI 助手可以从这两个工具导入模型供应商配置，标识用官方的。
- **终端分栏与命令面板。** 终端菜单里可以直接关闭分栏，键盘焦点会跟着你进入的分栏走；命令面板用鼠标悬浮时保留选中项，在搜索框里用方向键移动。

## 修复

- 本地文件面板进入空目录时误报 SFTP EOF。
- 恢复的标签页默认不再自动重连。
- AI 助手面板里「设置模型」现在跳到 AI 助手设置页。
- 命令面板、overlay 关闭按钮的命中区域，以及新标签页选择器的分组和滚动。
- RDP：限制服务端能让客户端持有的像素内存，异常或恶意的服务端不能再一次要求过多内存。
- 更新：macOS 的更新助手改为从完整 bundle 副本运行，替换更可靠。

## 改进

- 每个 PR 都跑完整的 Go 检查；race 检测拆成多个分片并缓存构建，门禁更快也更稳。
- 调试画廊里加了颜色样本。

## 安装

| 平台 | 包 |
| --- | --- |
| macOS（arm64、amd64） | `.dmg`、`.zip` |
| Windows（amd64、arm64） | `.exe` 安装程序 |
| Linux（amd64、arm64） | `.deb`、`.tar.gz` |

`SHA256SUMS` 覆盖所有文件，`SIGNATURES` 是每个包的更新签名；安装要求见 [README](https://github.com/t8y2/motty#-install)。

macOS 包用 Developer ID 证书签名、通过 Apple 公证并 staple，可以直接打开，也能自己更新。Windows 包仍未做代码签名（还没配置证书），SmartScreen 会提示；装上这一版之后，后续更新靠更新签名校验，可以原地完成。Linux 包不做代码签名；用 `install.sh` 装到前缀的版本能自己更新，`.deb` 由包管理器升级。
