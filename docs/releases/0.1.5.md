Motty 0.1.5：工具栏可以自定义显示哪些按钮和顺序；连接颜色带进主机卡片、标签页和文件窗口；文件面板能筛选、显示隐藏项、直接输入路径；MCP 拆成 HTTP 与独立服务两种接入，并可选择完全权限；AI 助手固定主连接，跨会话操作会标出真实目标。

## 新功能

- **自定义工具栏。** 设置 > 通用里可以分别改窗口、终端和 SFTP 三个工具栏：勾选显示哪些按钮、拖动或用方向键排序，改动立即生效；也可以全选、全不选或恢复默认。
- **连接颜色进入工作台。** 主机卡片会带上该连接的颜色和一条色标，标签页按所属主机的颜色着色（当前和悬停的更深），文件窗口的头部也跟终端一致。
- **文件面板：筛选、隐藏项、路径直达。** 每个面板能按名字筛选当前目录并显示命中数；可以切换显示隐藏文件；Command/Ctrl+L 直接编辑路径。
- **MCP 两种接入方式分开。** 设置 > MCP 把 HTTP 服务（用窗口里打开的会话）和独立服务（`mcp-serve`，用已授权主机）分成两块，各有自己的客户端选择、配置预览和复制按钮，选择分别保存。
- **MCP 的「全部允许」。** 两种接入都能选完全权限：执行命令、读写删除文件都不再逐次审批。选择时先弹出风险确认，确认后才保存；配置期间持续显示红色警告。独立服务下还额外提供 `sftp_write`、`sftp_remove`，并且要等客户端重启服务才生效；HTTP 的改动对新调用立即生效。
- **AI 助手固定主连接。** 主连接不随标签页切换而改变；要操作别的会话，得用 @ 指定或明确要求，跨连接的命令和文件改动在审批时会显示真实目标。
- **Docker 页面。** 服务器没装 Docker 时给出空状态和提示；列可以点标题排序；可以开自动刷新，间隔从 5 秒到 5 分钟。
- **更新说明按 Markdown 渲染。** 更新对话框里的 release notes 现在是排过版的 Markdown，链接可以点开。

## 改进

- 「询问」级别的含义写清楚了：低风险操作自动执行，其余在 Motty 的 AI 助手面板批准，极高风险操作需要输入确认文字。
- 自定义安装目录的 Windows 版本也能原地更新，升级继续用原来的目录；之前的版本若因自定义目录只给了浏览器下载，需要手动装一次这一版。
- Apple Silicon 上以 Rosetta 运行更新时，装的是 arm64 包，而不是再来一个 amd64。
- 状态图标在第一个窗口就绪之后才创建，启动更稳。

## 修复

- 设置等页面滚动时，内容不再越出工作区边框。
- 独立文件窗口里，传输的进度和结果留在它自己的底部，不再跑到主窗口。
- AI 助手抽屉不再压到对话框上。
